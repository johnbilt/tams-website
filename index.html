What is TAMS?

A practical implementation of time-addressable media principles

Developed by BBC Research & Development, TAMS is designed around storing media chunks in object storage behind an open API. Every frame has a time address — so broadcast, post, social, and VOD teams can all work from one store, by reference.

Learn more about TAMS →
Key benefits

One store, every workflow

01

Convergence

Broadcast, post-production, social, and VOD teams all sourcing content from a single store.

02

Cost effective

Commodity object storage and serverless tech — no high-performance file systems, no duplicated media.

03

Interoperability

A common API across vendors, so customers pick and choose the tools they want.

04

Open framework

An open-source spec — build on it without proprietary technology or licence fees.

05

Live + file, together

Built on the same reference architecture as NMOS — timing and identity preserved between live and stored domains.

06

Elasticity

Scales up and down with the business need — key for live workloads that are rarely constant.

07

Workflow acceleration

Segments readable the moment they're written, and edit-by-reference beats moving files.
